# 无人值守（HANDS-OFF）：把「上游动一下就要重发六个安装包」删掉

动机是一句话：**"我有点不想维护了。"**

今天上游每发一版的成本：

| 环节 | 成本 | 频次 |
| --- | --- | --- |
| 人发现新 tag、本地合并、解冲突 | 手工，最容易错 | 每次上游发版 |
| 重新对齐 `patches/game-client.patch` 锚点 | 手工，每次都会漂一两处 | 上下文变了就要 |
| `cut-payload`（搬 1 GB 素材、出代码增量） | CI 约 20 分钟 | 每次出包 |
| `build-clients` ×3 平台 + `build-tauri` | CI 约 25 分钟 | 每次出包 |
| `publish-client` 六个形态 | CI 约 5 分钟、上传约 4.8 GB | 每次出包 |
| 玩家重装 | 每人 800 MB | 每次出包 |

六份产物里有五份是同一份游戏内容的重复字节。**要降维护量，有效的办法只有一个：不把游戏本体烤进安装包。**

目标架构两条腿，各自独立可落地：

- **腿 A：服务端自动同步** —— 上游发版到服务端上线之间没有人的步骤（§1，**已落地**）。
- **腿 B：通用客户端** —— 安装包里只有壳（约 40 MB），游戏本体运行时从所连的服务器取，本地只做缓存（§2，下一步）。

## 1. 服务端自动同步（已落地：`auto-sync.yml` 的 `auto` 模式）

`auto-sync` 原来只有 `report`（每天量一次代价，什么都不推）与 `branch`（零冲突且补丁打得上就推 `auto/` 分支）。
`auto` 模式补上最后一段：把这一刀合进服务端上线分支，让现有的 deploy hook / timer 自己把它上线。

四道门槛，缺一道就一个字节都不推（这条 lane 推的东西，几分钟内就有 300 多个玩家在用）：

1. **严格合并零冲突** —— `git merge --no-commit`，不用 `-X theirs`（那种合并会替人把冲突"解决"掉，闸门就变成自动发坏包的绿灯）。
   冲突要在**目标分支那棵树**上重算一遍：`report` 那一跑量的是 `BASE_REF`，而推的是 `LIVE_REF`，两棵树的冲突数不是同一个数。
2. **`patches/game-client.patch` 在合并结果上打得上** —— 自动出包真正会红的就是这一处（`tools/check-patch-applies.mjs`）。
3. **游戏仓完整 `npm test` 绿** —— 照抄 `test-game-branch.yml`：从最新的 `payload-*` Release 补 1 GB 素材 →
   `fetch-assets` 补增量素材 → `npm test`。顺手浅取一个 `upstream/master`（ext-surface 那条 "no unrecorded mount points" 要这个 ref，没有它是直接抛的，红在环境而不是红在合并上）。
4. **仓库变量 `AUTO_SYNC_LIVE=on`** —— 止损开关：出错或上游连续坏提交时**改一个变量就能停**，不用回滚 YAML。
   默认 `off`：第一次跑会一路量到"合并 + 套件全绿"，然后告诉你"什么都没推，要不要开"。

任何一道不过 → 落成带 `auto-sync` 标签的 issue（已存在的那条会被追加而不是刷屏），并把这一刀的报告存档。
**人要处理的只剩真冲突那几类**：日常那种"上游加了点东西"的版本会自动走完。

回滚命令写在推成功的日志里：`git reset --hard <推之前的 HEAD> && git push --force-with-lease`。
推完还会 `ls-remote` 核一遍 sha —— 不信 push 的退出码（这条教训来自 `publish-client`）。

### 怎么开

```
gh workflow run auto-sync.yml -f action=auto                       # 单跑一次，看它怎么说
gh variable set AUTO_SYNC_LIVE --body on                           # 想让它真自动上线
gh workflow run auto-sync.yml -f action=auto -f live_ref=deploy/prod -f payload_release=payload-v0.3.0-c46
```

`schedule` 仍然是 `report`（每天一次，只量不推）。**不建议**直接把 schedule 改成 `auto`：那意味着上游任何时候发版都会在凌晨自动上线。
`auto` 是"人在旁边点了按钮"的那一条。

## 2. 通用客户端（设计，下一步）

### 思想倒过来的那一刀

今天：服务器只提供对局，客户端自带整份游戏。
以后：**客户端 = 一台专为这个游戏做的浏览器 + 本地缓存 + 选择器 + 联机 sidecar；游戏本体属于服务器。**

这正是网页版已经在做的事 —— 网页版之所以"永远是最新的"，就因为它是从服务器取的。
我们要做的只是把网页版的优点（即时更新、不必发安装包）搬到桌面 / Android / iOS 上，同时补掉它的缺点（要联网、立绘每次重下、打开慢）。

### 怎么工作

```
启动 → 连 <server> → GET /healthz 读到 build 指纹
     → 本地缓存根 <userData>/cache/<host>/<build>/
     → 页面请求 http://127.0.0.1:<port>/<path>
          命中缓存 → 直接发
          未命中   → 回源 GET <server>/<path>，存盘后再发
```

三点为什么是这样：

- **`build` 指纹当缓存版本**。`server/http/buildTag.js` 早就算了这个值（服务端文件的 size+mtime 的 sha1），它原来的用途是"你的页面过期了"，
  这里正好当缓存目录名：服务器发布了新代码 → 指纹变 → 换目录 → 客户端自动看到新版，**不用发 installer**。
- **origin 还是 `127.0.0.1:<port>`**。localStorage（身份 token、编队、设置、记住的服务器）与今天完全一样，不会"每次启动像新装"。
- **WebSocket 不经代理**。`net.js` 本来就直连远端（`__SP_SERVER__`），走的是今天那条路。

### 美术是唯一的例外，必须写清楚

19,404 个文件 / 约 1 GB 逐个 HTTP 取是不行的（冷启动变成几千个往返）。
美术继续走**整包**：现有的美术指纹机制（`desktop/updater.mjs` 的 `artDigest`，与 cut-payload 那句 `sha256sum | sha256sum` 同形）
整条搬过来 —— 一次整包、按需，而不是每次都重下。
**代码**（几百个文件、几 MB）走逐文件 live cache —— 那才是真正每次都变的那半边。

### 风险与各自的闸门

| 风险 | 闸门 |
| --- | --- |
| 服务器关了 / 连不上，玩家打不开游戏 | 退回**已知最新的那份缓存**，并明确告知"离线，正在玩 <build> 这份"。首次安装必须联网（这条要写在下载页）。 |
| 服务器推了坏代码（issue #18 那类视觉回归） | ① 服务端那边由 §1 的 `npm test` 先拦一道；② 客户端保留"上一次那份缓存"，按 F2 换服即可回退；③ `--board 2d` 这类开关继续存在。 |
| 换服务器时两套缓存互相污染 | 缓存按 `<host>` 分目录，LRU 保留 2 份。 |
| 首次冷启动慢 | 只拦 `index.html` / `js` / `css` / `data`；美术整包单独预取。 |

### 迁移路径（每一步都可回退）

| 阶段 | 做什么 | 风险 |
| --- | --- | --- |
| 0 | ✅ `v0.3.0-c47` 已发：桌面端能自动更新代码增量（胖客户端老路，但能用了） | 无 |
| 1 | ✅ `auto-sync` 升到 `auto`：服务端自动跟上上游 | 由闸门里的 issue 兜底 |
| 2 | 壳加 live 模式（`--live`），**默认仍走内嵌 payload**，两头都能跑 | 零：玩家不受影响 |
| 3 | live 转默认；发一次"瘦客户端"（约 40 MB）；旧的胖客户端停止更新但仍可用 | 低 |
| 4 | 六个形态里那五份游戏相关的不再每版重发，只在壳自己升级时发一次 | 中：要先跑满一个阶段 |

移动端（apk / ipa）留在阶段 0–1：Capacitor 的服务层与我们手写的 `serve.mjs` 不是同一份，
live cache 这条路今天只在 Electron / Tauri 上成立，手机先不动。

## 3. 一句话

这条路的终点是：**你不用再为"上游发了一版"做任何事，也不用再为它发任何安装包。**
服务端自己同步（§1），客户端自己取（§2）。人真正要处理的只剩下两件事：

- 真的冲突 —— 自动 lane 会开 issue 叫你；
- 真的有坏的一刀发给了全部玩家 —— 回滚是一条 Git 命令。
